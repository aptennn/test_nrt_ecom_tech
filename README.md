# test_nrt_ecom_tech
## Тестовое задание nrt для ecom.tech
## Стурктура проекта
`main.py` - основной файл для запуска

`data_generator.py` - файл для генерации .parquet файлов

`config.py` - файл настроек

В проекте используется S3 совместимое хранилище (Minio), ApacheSpark.


В папке data содержаться результ обработки данных и сами данные на которых была произведена обработка 

## Варианты запуска и настройки
Для загрузки своих данных нужно использовать способ запуска локально
### C помощью Docker
Скачиваем репозиторий 
и пишем в терминале
`docker-compose up`

Загрузка библоитек может занимать около 10 минут

Чтобы посмотреть результат открываем страницу http://localhost:9001
Ввводим логин и пароль (по умолчанию minioadmin minioadmin)
Переходим в бакет data-bucket в папке result.parquet и будет результат.

### Локально
устанавливаем все нужные библиотеки 'pip install -r requirements.txt'


в `config.py` меняем переменную `LOCAL_MODE = True`

чтобы сгенерировать данные запускаем `data_generator.py`


или загружаем свои .parquet файлы в папку data

запускаем `main.py`
